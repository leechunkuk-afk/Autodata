# Autodata

비개발자를 위한 AI 실용 자료실. [참고한 원본 자료실](https://nondev-thinking.web.app/library/)의 주제를 바탕으로, 준비물 → 설명 → 실습 → 결과 확인으로 이어지는 새로운 사이트를 구성했습니다.

## 포함된 내용

- 9개 주제 가이드: 영상 주문, 편집 효과, 모션그래픽, 업무 도구, Claude Code, Codex, 용어, 참고 자료 분석, 판단 자동화
- 가이드별 3개 본문, 맞춤 요청문, 확인표, FAQ, 원본 링크
- 30개 핵심 용어: 뜻 / 예시 / 다음 행동
- 회의록 실습: 결정·담당자·기한 입력, 미정 표시, Markdown 저장
- 영상 주문서 실습: 시간 검증, 효과 3종 움직임 예시, 요청문 저장
- 분류 검증 실습: 편집 가능한 키워드·정답 사례, 일치/불일치 비교, 결과 저장
- 검색, 분야 필터, 저장한 자료, 학습 진도, 모바일 대응

원본의 수백 개 효과·견본과 38개 도구를 복제한 사이트가 아닙니다. 새 원고와 3개 자체 실습을 제공하며 원본 전체 목록에는 출처 링크로 연결합니다. 영상 렌더링, 실제 Jev 호출, 계정·기기 간 동기화는 포함하지 않습니다.

## 로컬 실행

Node.js 22.12 이상 또는 지원되는 최신 LTS 환경에서:

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

## 구조

```text
src/content/guides.js   가이드 원고·출처·확인표
src/content/terms.js    용어 원고
src/pages/             자료실·가이드·용어·실습 화면
src/components/        공통 UI
src/lib/domain.js      실습 처리와 검증 로직
src/lib/storage.js     브라우저 저장 및 파일 내보내기
src/styles.css         디자인 토큰·반응형 스타일
tests/                 시간·결과·분류·콘텐츠 연결 검증
docs/                  디자인·검증·콘텐츠 편집 안내
```

## 데이터와 실행 범위

입력과 학습 기록은 `localStorage`에 저장됩니다. 외부 AI API나 분석 도구를 호출하지 않습니다. 외부 AI에 요청문을 붙여넣는 행동에는 해당 서비스의 정책이 적용됩니다. 글꼴은 Google Fonts에서 내려받으며 네트워크가 없으면 시스템 글꼴로 표시됩니다. 비밀 키나 개인정보를 예제에 넣지 마세요.

## 배포

`npm run build`의 `dist`를 정적 호스팅에 배포할 수 있습니다. 상대 자산 경로와 해시 라우팅을 사용해 GitHub Pages의 하위 경로에서도 새로고침할 수 있습니다.

GitHub Actions 워크플로는 테스트와 빌드 후 GitHub Pages에 배포합니다. 저장소 Pages 설정의 Source는 **GitHub Actions**를 사용합니다. 기존 Firebase 사이트에 연결하거나 덮어쓰지 않습니다.

## 원고 수정 원칙

기능 이름·모델 이름·요금은 확인 없이 단정하지 않습니다. 원고 개정일과 제품 기능 검증일을 혼동하지 않습니다. 도구나 개수를 늘릴 때 실제 데이터에서 집계합니다. 원본 매체를 가져올 때는 사용 권한과 출처를 먼저 확인합니다.
