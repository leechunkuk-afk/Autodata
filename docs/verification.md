## 실제 브라우저 검증

Codex 내장 브라우저(IAB)에서 프로덕션 빌드를 실행했습니다. 별도의 Playwright 브라우저 대체는 사용하지 않았습니다.

- 자료실: 9개 목록, 분야 필터, 검색 결과 없음과 초기화.
- 자료 저장: 저장 후 새로고침 → 저장한 자료 필터에서 유지됨.
- 가이드: 체크 전 완료 시 안내, 3개 확인 후 완료 기록, 요청문 복사 성공, 연결 실습 이동.
- 9개 가이드의 경로와 제목 확인, 모바일 가로 넘침 없음.
- 영상 주문서: 끝이 시작보다 빠르면 오류와 내보내기 차단; 자막·끝 시간·효과 변경이 출력과 미리보기에 반영; 텍스트 파일 다운로드와 파일 내용 확인.
- 회의록: 빈 담당자/기한은 미정, 할 일 추가 후 빈 내용이면 내보내기 차단, 입력 후 새로고침에도 초안 유지.
- 분류: 기본 예제 6건 중 5건 일치, 사람 확인 3건. 규칙 수정 시 이전 결과 제거. 수정 후 다시 실행한 결과 6건 일치, 사람 확인 2건. 이것은 학습용 규칙의 결과이지 AI 성능 수치가 아님.
- 용어사전: API 검색 시 관련 2개 항목, 예시와 다음 행동 표시.
- 브라우저 콘솔 오류 없음.

## 시각 검증

생성한 디자인 방향과 실제 브라우저 스크린샷을 `view_image`로 비교했습니다. 데스크톱 viewport 1435×1096, 모바일 390×844, 좁은 화면 320×800을 확인했습니다. 스크롤바가 있는 환경의 실제 문서 폭은 viewport보다 작습니다.

| 점검 | 결과 / 의도적인 차이 |
| --- | --- |
| 제목·안내·CTA | 핵심 문구와 순서 유지. 검색 예시는 실제 기능에 맞게 구체화 |
| 배치 | 2열 첫 화면 → 3단계 안내 → 검색·분류 → 3열 목록 유지. 본문 최대 폭 1160px |
| 글꼴·위계 | 한국어 산세리프, 굵은 제목, 본문·메타 정보·컨트롤 위계 일관 |
| 색 | 흰 바탕, 숲색 버튼과 텍스트, 옅은 민트 패널 유지. 오버레이·그라데이션 없음 |
| 간격·컨테이너 | 얇은 테두리, 둥근 모서리, 반복되는 패딩과 여백 적용 |
| 모바일 | 한 열로 자연스럽게 전환. 안내·검색·목록·모든 가이드에서 넘침 없음 |
| 실제 콘텐츠 | 이미지의 예시 6개 카드를 실제 9개 자료로 확장. 저장·진도와 관련 실습 추가 |
